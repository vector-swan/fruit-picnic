# Sound labs

Pages for trying out Fruit Picnic sounds before they go into the game. Open any of
them in a browser (double-click the file) and press play. They aren't part of the
game: the website and iPhone builds only copy the files listed in
`scripts/build-www.mjs`.

- `picnic-music-lab.html`: background music styles, alone or under the game
  sounds, with controls to change each song.
- `kalimba-variations.html`: the current merge sound next to variations of it.
- `fruit-picnic-sound-lab.html`: eleven complete sound sets to compare.

Each page uses the game's own sound code, copied in, so if the sounds in `game.js`
change, these pages won't follow along by themselves.
